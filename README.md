專案簡介
---
（介面語言：English）

播放、收藏與下載串流音樂的桌面播放器，支援 YouTube、Bilibili、Spotify、SoundCloud，並會自動推薦「相關」的歌曲接著播。

支援平台
---

| 平台 | 搜尋 | 貼連結 | 播放方式 |
|---|---|---|---|
| YouTube | ✓ | 影片、Shorts、播放清單 | 直接串流 |
| Bilibili | ✓ | 影片、分 P、b23.tv 短網址 | 直接串流 |
| Spotify | – | 歌曲、專輯、播放清單 | 讀取歌曲資訊後，自動對應到 YouTube 播放（Spotify 音訊有 DRM） |
| SoundCloud | ✓ | 歌曲、歌單 | 直接串流 |
| 其他網站 | – | yt-dlp 支援的連結 | 直接串流 |
| 本機檔案 | – | 「收藏 › 加入檔案…」 | 直接播放 |

自動推薦
---
播放列右側的 ✦ 開啟時，佇列播完會自動接上推薦的歌；「播放中 › 推薦」可以隨時查看與挑選。

- 推薦一律來自 YouTube。正在播的若是 Bilibili、Spotify 等其他平台，會先找出對應的 YouTube 影片當作推薦依據。
- 推薦的是**相關**而不是**相同**：同一首歌的翻唱、Live、Remix、歌詞版、重新上傳、簡繁不同的標題，都視為「同一首」並排除；已播過或已在佇列中的歌也不會再出現。
- **原作優先**：歌詞版、動態歌詞、加速／降速、Nightcore、Remix、二創剪輯、伴奏、AI 翻唱等衍生影片不會被推薦；其他歌的翻唱、Live 可以推薦，但排在官方原版之後。
- 以目前這首為主，再綜合整個佇列（前、中、後段各取一首）與最近播過的歌，並避免同一位歌手連續出現；編輯佇列後推薦會跟著更新。若推薦來源幾乎都是同一位歌手，會從你常一起聽的其他歌手延伸出去。
- 依你的習慣微調順序：你常和這些歌手一起聽的歌手、收藏裡的歌手、同時出現在多個推薦來源的歌手會稍微往前排；合輯與串燒影片會被排除。
- **節奏流動（Tempo Flow）**：「設定 › Playback」開啟後，推薦的歌會優先安排 BPM 相近的接著播，連續幾首相近後再平順地往稍快或稍慢移動（可選 Gentle／Balanced／Strong）；把 70 與 140 這類半拍／雙拍視為相近，估測不可靠或未知時不影響原本的推薦。「Tempo Flow Scope」預設為 Recommendations Only（只調整推薦歌曲）；選 Include Playlists 時，播放播放清單或智慧收藏也會從你點的那首開始依節奏安排這次的播放順序，並隨 BPM 分析逐步調整——播放清單本身的順序不會被改，隨機播放維持隨機，專輯一律照原始曲序，你手動調整佇列後 Aria 就不再重排。不會改變播放速度。BPM 由 Aria 在背景、以閒置優先權分析歌曲中段 30 秒（已下載的讀本機檔，串流只取那一小段，不會下載整首），結果快取一年；知道時會在「播放中」以「· 87 BPM」低調顯示
- **探索程度（Discovery）**：「For You」上方的滑桿，往左（♡）偏向收藏過、常聽的歌手，往右（羅盤）偏向沒聽過的歌手；調整時直接重新排序，不必重新抓取。

使用說明
---
執行環境：Windows 10 / 11，Python 3.10 以上（專案已附 VLC 3.0.18）。

```bash
pip install -r requirements.txt
python main.py
```

YouTube 經常改版。若出現「無法播放」，在「主控台」輸入 `update` 更新 yt-dlp 後重新啟動即可。若電腦裝有 [Deno](https://deno.com) 或 Node.js，yt-dlp 會用它解 YouTube 的簽章，相容性更好。

### 介面

- **播放中**：封面、佇列（可拖曳排序）、推薦、播放紀錄、歌詞；背景會依封面微微上色（Smart Artwork，低飽和度）
- **聆聽階段（Sessions）**：「History › Sessions」把每段連續聆聽整理成卡片，例如「October 9 · Evening Session — 18 tracks」，記錄開始時間、實際聆聽時長、播放順序與期間收藏的歌；點開可重播或存成播放清單。停止聆聽 30 分鐘後該段結束
- **時長適配播放**：佇列上方的計時器按鈕，選 25／45／60 分鐘或自訂（例如 31:25），從收藏或目前佇列挑出總長最接近、又不超過的歌，最後一首會自然結束；從佇列挑時若時間不夠，會用自動推薦補滿；佇列上方與狀態列會倒數剩餘時間
- **搜尋**：輸入關鍵字，或直接貼上任何支援的連結；歌單連結可一次加入佇列或收藏
- **收藏**：收藏的歌、下載（可離線播放）、開啟下載資料夾、匯入／匯出歌單（相容 v1 的 JSON）
- **List／Disc Rack**：收藏與播放清單的工具列右側可切換成 CD 架——每首歌是一張直立的單曲 CD，書脊顏色取自封面（低飽和）；滑過或用方向鍵選到時，CD 盒會稍微抽出、露出部分封面，後面的盒子自動讓位，不遮住任何一張。書脊頂端下方一點的短橫線表示可離線播放（實線＝已下載；專輯／播放清單半實線＝部分已下載），未下載的維持原樣、不會變灰；下方資訊列會寫出 Available Offline／Stream Only。單擊選取並在下方顯示資訊，雙擊播放，右鍵與清單相同；兩種視圖共用篩選與選取，會記住最後使用的視圖
- **唱片架（Shelf）**：右上角 Cover／Spine 切換正面陳列或側面書脊；Spine 模式滑過時專輯盒會抽出約一半、露出封面，點一下打開。把喜歡的專輯與播放清單照自己的順序排在架上（Cover 模式可拖曳排序）；點開以唱片內頁呈現曲目與資訊。可用名稱搜尋、貼上 Spotify 專輯／播放清單、YouTube 播放清單、Bilibili 多 P 連結，或放上自己的播放清單（會即時同步內容，封面為歌曲拼貼）
- **專輯完整播放**：在唱片架打開專輯按 Play（或雙擊任一首），會照原始曲序播放、曲目之間無縫銜接、期間不插入自動推薦；專輯播完後一切恢復原狀（原本的佇列接在後面）
- **播放清單**：側邊欄 Playlists 旁的 ＋ 建立；任何歌曲右鍵 › Add to Playlist，正在播放的歌可用播放列的清單按鈕或 Ctrl+P 加入
- **智慧收藏（Smart Collections）**：同一個 ＋ 選「New Smart Collection」，用條件自動組成清單並隨收藏與播放紀錄更新，例如「最近 30 天收藏」「收藏但還沒完整聽過」「已下載的日文歌」；條件可組合（全部符合／任一符合），可只看收藏或連同聽過的歌
- **快速命令（Ctrl+K）**：浮動的命令框，可搜尋歌曲（先找自己的音樂，再找 YouTube）與執行功能，例如 Add to Playlist、Download Current Track、Switch Source、Open Shelf、Listen for 25 Minutes；↑↓ 選擇、Enter 執行／播放、Shift+Enter 加入佇列
- **移除時可一併刪檔**：從收藏或播放清單移除已下載的歌時，可勾選「Also delete downloaded files」；正在播放的那個檔案會等這首歌結束後再刪除
- **主控台**：即時紀錄與指令列，輸入 `help` 查看所有指令。每則訊息只佔一行（太長會依視窗寬度截斷），時間、來源（activity、playback、switch、settings、notice…）各有顏色，行內的歌名、服務（YouTube 紅、Spotify 綠）、數字與 ✓ ✗ → ▶ 等標記也以不同顏色標示；會記錄播放／暫停／跳轉、佇列與收藏變化、推薦、BPM、下載、輸出裝置、音量與設定變更，所有跳出的提示訊息也會寫進來；右上角顯示目前則數。設定 → Console 可選擇累積 200／500／1000 則後自動清空，或不清空（保留最新 2000 則）
- **切換來源（Switch Source）**：任何地方的歌（收藏、播放清單、佇列、推薦、歷史、搜尋結果、正在播放）右鍵 →「Switch to Spotify」，會在網路上找出同一首歌的 Spotify 版本，比對歌名、歌手與長度確認是同一首（Remix、Live 或長度差太多的版本不會被採用）才替換；換成 Spotify 後仍播放原本那支影片，音質與下載都不變。Spotify 的歌也可以「Switch to YouTube」換回來。可多選批次處理，狀態列會顯示進度；收藏位置、播放清單、佇列、下載檔、聆聽紀錄與 BPM 都會跟著保留，正在播放的歌會直接換成新來源、不中斷播放
- **設定**：左側大綱可直接跳到 Playback、Audio、Library、Backup、Lyrics、Appearance、Window、Data、Console，捲動時會跟著標示目前段落。包含自然過渡、柔和恢復、自動推薦、下載後改播本機、輸出裝置、音量平衡、外觀、Smart Artwork、減少動態效果、關閉時縮到系統匣、清除快取（封面、歌詞與串流資料；不會動到收藏與下載的歌，也可用 Ctrl+K 或主控台 `cache clear`）、釋放空間（Free Up Space：刪除所有已下載的歌曲檔案，歌曲仍留在收藏與播放清單中，之後改用串流播放；正在播放的那首會在播完後刪除）
- **收藏庫整理（Collection Health）**：「設定 › Library › Check Library…」檢查已下載卻不在收藏裡的檔案、重複收藏的同一首歌、遺失的本機檔案、重複下載的音檔，「Check Links」可再檢查失效的連結；每項都附修正建議，可逐項或整組修正
- **收藏庫快照（Library Snapshot）**：「設定 › Backup」每天或每週自動備份收藏、播放清單與智慧收藏、唱片架、佇列與播放紀錄、聆聽階段與統計、設定（保留最近 10 份自動快照），也可手動備份；可還原到任一時間點（會先備份現況再重新啟動）。「Export… / Import…」把完整資料（可選擇連同下載的歌）帶到另一台電腦，本機檔案路徑會自動對應到新電腦的下載資料夾
- **音訊裝置記憶**：「設定 › Audio › Output」可選輸出裝置（或跟隨系統預設）；每個裝置各自記住音量與音量平衡，例如耳機 35%、喇叭 65%，切換時自動套用；選定的裝置斷線時會改用預設輸出，接回後自動切回

### 沉浸模式（Immersive Mode）

「播放中」封面下方的展開按鈕或 `F11` 進入全螢幕的沉浸式播放：大型封面、歌名與歌手、同步歌詞與一條細細的播放進度，背景是低彩度、模糊的封面色調。可切換「置中封面」與「編輯式排版」（`V`），開關歌詞（`L`）；沒有同步歌詞時顯示一般歌詞，沒有歌詞時就是純封面。點歌詞可跳到該處，點進度條可跳轉。音量可用控制列的滑桿、`↑`／`↓`、`M` 靜音，或在歌詞以外的地方捲動滑鼠滾輪調整（與主視窗同步）。移動滑鼠時顯示播放控制，閒置 3 秒後連同游標一起隱藏，歌詞持續顯示。`Esc`、`F11` 或雙擊離開；音樂不會中斷，佇列、音量、Tempo Flow 與自然過渡都照常。背景、封面陰影與標題只在換歌或改變大小時重畫並快取，其餘只重畫歌詞與進度。

### 歌詞

歌詞來自 [LRCLIB](https://lrclib.net)，有時間軸的歌詞會跟著歌曲捲動，點一行可跳到該處。在設定開啟「強化歌詞抓取」後，歌詞庫找不到時會從影片說明欄與留言中找出像歌詞的段落（留言裡附時間的歌詞也能同步）。在歌詞上按右鍵可複製該行或從該行播放。

### 播放

- **自然過渡**：歌曲結尾與下一首交疊淡入淡出（3／6／9／12 秒）；單曲重複時也會無縫接回開頭，按「上一首」重播也不會有斷點
- **柔和恢復**：暫停超過一分半後繼續，音量從小慢慢回來
- **接續上次**：關閉時會記住正在播的歌與播放位置，下次按播放就從那一刻繼續；在「設定 › Playback」開啟「Resume Where I Left Off」後，啟動時會自動接著播（關閉前若是暫停，就停在那一刻）
- **依節奏排序佇列**：佇列上方的波形按鈕，用 Tempo Flow 的規則把目前佇列依 BPM 重新排序（未開啟 Tempo Flow 也能用），還沒量到 BPM 的歌會優先在背景分析並逐步調整，佇列上方與狀態列會顯示「Measuring tempo 3 / 12」和進度條；旁邊的復原按鈕可回到原本順序，手動調整佇列後就不再自動重排
- **來源切換**：播放中的歌下載完成時會無縫改從本機檔案播放；也可以在「播放中」用「串流／本機」手動切換
- **系統匣與迷你播放器**：關閉視窗後繼續在背景播放；迷你播放器永遠置頂、可拖曳，也能調整音量（與主視窗同步）
- **音量平衡（Volume Balance，Windows）**：按音量滑桿右邊的天平按鈕，滑桿就變成 Aria 與其他程式的相對音量——往右突出 Aria（調低其他程式），往左讓其他程式更清楚（調低 Aria），中間維持原狀；只會調低另一方，不會突然變大聲。依分貝調整，越靠近中間變化越細微（四分之一約 -1 dB、一半約 -5 dB、最邊 -24 dB），所有輸出裝置上的程式都會套用，拖曳時會顯示兩邊目前的音量比例。其他程式的原始音量會在回到中間或關閉 Aria 時還原（即使 Aria 異常結束，下次啟動也會還原）。「設定 › Audio」可排除特定程式（Discord、Teams、Zoom 等通話軟體預設排除），或改成只管理選定的程式

提示框只出現在圖示意義不夠直覺、或操作需要多一點說明的地方（播放、上一首、收藏這類一看就懂的按鈕不再跳提示，但仍保留無障礙名稱）；側邊欄收合時才顯示頁面名稱；名稱被截斷時才顯示完整名稱。在清單上按右鍵有完整動作選單。

### 資料

收藏、佇列、播放清單（含智慧收藏）、唱片架、聆聽階段與播放統計、設定、下載的音檔與快取都放在 `data/`。第一次啟動時會自動匯入 v1 的 `assets/saved.json` 與 `assets/queue.json`。

專案結構
---

```
aria/
  core/        資料模型、播放（VLC）、佇列與推薦、收藏與下載、儲存
  providers/   各平台的搜尋、連結解析、串流與下載
  ui/          PySide6 介面：主題 token、元件、頁面
tests/         標題比對、推薦過濾與排序、時長適配、智慧收藏、聆聽階段、歌單匯入的測試（pytest）
```

介面依循〈介面設計規範〉：色彩只透過 token 取用、跟隨系統深淺色、同列控制項等高 30、圓角不超過短邊 1/3、畫面上不放操作說明。

本專案強調色：淺色 `#507768`、深色 `#93bead`（HSL 157° / 20%，依規範 §1.3 一次抽定）。
